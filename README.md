# EstateHub – Real Estate Platform

A portfolio-ready frontend real-estate marketplace built with HTML, CSS and JavaScript.

## Features
- Property search and filtering
- Property detail pages
- Favorites using localStorage
- Compare up to 4 properties
- Recently viewed tracking
- Login/signup simulation
- User dashboard
- Agent directory
- Contact form
- Dark mode
- Responsive design
- JSON property data

## Run
Because the project loads `data/properties.json`, use a local server rather than opening `index.html` directly.

### VS Code Live Server
Open the folder and run Live Server.

### Node live-server
```bash
npx live-server
```

### Python
```bash
python -m http.server 8000
```
Then open http://localhost:8000

## Note
This is a frontend demo. Authentication, payments, property verification, messaging, and persistent database operations require a backend such as Node.js/Express, Django/Flask, Firebase, Supabase or another server/database.
